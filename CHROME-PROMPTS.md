# Chrome prompts — short version

The earlier version of this file was too long. Browser assistants act on one
clear instruction at a time, not on a page of rules. Everything below is one or
two sentences.

Type them one at a time. Wait for it to finish before sending the next.

---

## Setting up the account

```
Go to cjdropshipping.com and start a free account signup for me.
```

```
What does this form need from me?
```

Type your own email and password. When it asks for a code from your email:

```
I've verified my email. What's next?
```

```
Set my shipping country to United States.
```

---

## Finding one product

Start here. Do not move on until this works.

```
Search CJdropshipping for "fridge organizer bins set".
```

```
Show me only the ones that ship from a US warehouse.
```

```
For the top 3, give me the price, the shipping cost to Ohio, and the link.
```

```
Which one has the most orders or reviews?
```

That is the whole method. Four short prompts per product.

## If it still refuses

Some pages block automated browsing, and a signup with a CAPTCHA has to be done
by hand. If it stalls, do that one step yourself and then carry on with the next
prompt — the assistant does not need to have done the earlier step itself.

## What to bring back

A table with: product, SKU, cost, shipping, total, link, image URL.

Paste it into the chat and it gets wired into the shop from there.
